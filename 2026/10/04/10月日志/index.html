T1 游戏（game）

  • 题意：给定一棵 个节点的树，边权为 0 或 1。每次询问给定一个根节点 ，女生先手，双方轮流操作：选择一条非根节点且边权为 1 的边，将该节点到根的路径上所有边权翻转。无法操作者败。需支持单条边权修改操作，回答每次询问的胜者。
  • Sol：：维护每个节点的相邻边权之和（即与该点直接相连的边权总和）。对于每次询问 ，若 的相邻边权和为奇数，则先手必胜（Girls win!），否则后手必胜（Boys win!）。
  • 博弈结论证明：
    1. 终局状态：若树中所有边权均为 0，游戏结束。此时根节点 的相邻边权和为 0（偶数），先手无路可走，为必败态。
    2. 奇偶态转移：假设当前根节点 的相邻边权和为 。
      • 若 为奇数：此时 必定至少有一条相邻边权为 1。先手可以直接选择该边的子节点进行操作，此时路径只包含这一条边，翻转后该边变为 0，其余相邻边不变。因此 变为偶数。先手将必败态留给了对手，故当前为必胜态。
      • 若 为偶数：
        • 若 ，无操作可做，为必败态。
        • 若 ，先手无论选择哪条满足条件的边进行翻转，其路径 中，只有与根节点 直接相连的那一条边（设为 ）被翻转。因此， 必然发生改变（边权 或 ），奇偶性必从偶数变为奇数。即先手无论怎么走，都会把必胜态留给对手。故当前为必败态。
          由以上推导可知，局面为必胜态当且仅当根节点的相邻边权和为奇数。

T4 行走于真实之道（path）

Sol

题解链接。

首先从源点向所有 1 连容量 的边，所有 1 向汇点连容量 的边，从源点向所有 0 连容量 的边，所有 0 向汇点连容量 的边，所有 1 向右侧 0 连容量为 1 的边。

我们要最大化最终收益。由于本题每个字符都要二选一（选红或选蓝），我们可以套用最小割模型。

具体做法是：先假设把所有的钱 () 都拿到手，即将每个点连接源点和汇点的点都连上，然后找出所有可能让我们损失钱的情况。

同一个点连接了源点和汇点，肯定选其一断掉；如果最优解中源点连接了 1，经过一条 1 → 0 的边，又从 0 连到汇点（这就是均染红色的情况），那么中间这条边就会进入割，要断掉。

所以最小割割掉之后，刚好对应一个每个点恰好选一种颜色，且减去支出了的合法解。

答案就是 。

由于最大流等于最小割，因此转化为求最大流。

首先每个点显然有 的流量。

对于 1 ，还有 的从源点来的入流量，对于 点，还有 到汇点的出流量。

所以我们就要通过 1 → 0 边用上这部分流量。

从左往右扫，遇到 1 就把 当作“可用额度”存起来；遇到 0 就消耗前面的额度来增加当前最大流。

贪心地，我们使用优先使用额度最大的元素消耗，因为每个额度价值相同，但是如果先消耗额度小的元素，可用元素数会减少，对于后面的 0 就不优。

动态插入并排序，后缀减，清除额度归零的元素，这可以用平衡树维护。

注意后缀减时导致分裂的两部分相接处不符合 BST 性质的情况，需要多分裂两次交换顺序合并以维护平衡树 BST 性质。
